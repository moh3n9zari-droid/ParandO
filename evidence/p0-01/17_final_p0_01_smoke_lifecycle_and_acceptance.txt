1. MISSION OVERVIEW & DEFECTS REMEDIATED IN SMOKE TEST SUITE
--------------------------------------------------------------------------------
Objective:
Finalize P0-01 (Production Boot and Local Production-Grade Delivery) by correcting
demonstrable reliability gaps in the existing production smoke test suite,
verifying the complete process lifecycle (distinguishing signals sent from actual
process exit, awaiting child process exit with bounded timeouts, ensuring cleanup
of detached process groups, verifying restart process termination), running a
controlled negative check, and executing the full local CI sequence.

Defects Remediated in `scripts/production_smoke.ts`:
1. Process Exit Event Verification:
   - Previously, the initial server process awaited `exit`, but the restarted
     server only called `killProcess` and `waitForPortFree` without explicitly
     observing and asserting the child process's `exit` event.
   - Implemented `terminateServerGracefully(child, signal, timeoutMs)`:
     * Registers `child.once('exit')` before dispatching signals.
     * Dispatches `SIGTERM` to the process group (`process.kill(-child.pid)` with
       fallback to `child.kill`).
     * Escalates to `SIGKILL` on the process group if process does not exit within
       75% of bounded timeout (6000ms).
     * Strictly verifies exit event and asserts `code === 0 || signal === 'SIGTERM'`.
     * Both the initial server and the restarted server now undergo identical,
       strict exit event assertions and port freedom confirmations.
2. Process Group Signal Discipline:
   - Enhanced `killProcess` and `cleanupAll` to use process group targeting
     (`process.kill(-child.pid, ...)`) when detached, preventing orphaned child
     processes or detached worker processes from leaking.
3. Premature Startup Failure Detection:
   - `waitForServerReady(child, port, timeoutMs)` now checks `child.exitCode`
     and `child.signalCode` on each poll interval, instantly failing with an
     informative error if the spawned child process dies prematurely rather than
     hanging for the full 15s timeout.
4. HTTP Request Socket Timeout Hardening:
   - Added explicit `timeout: 5000` and `req.on('timeout', () => req.destroy(...))`
     to `httpRequest` to prevent hanging sockets during probe failures.
5. WebSocket Event Guarding:
   - Added `settled` guards and explicit timeouts with `ws.terminate()` in tests
     for `/ws`, `/ws/competitions/:id`, and `/invalid-ws-route` to guarantee no
     lingering sockets or double assertions.
6. Built-in Controlled Negative Check:
   - Added `SMOKE_FORCE_FAIL=1` trigger in `scripts/production_smoke.ts` to allow
     deterministic, repeatable validation that an assertion failure exits with code 1.
