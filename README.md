# حراج ملی پرندو (Parando Auction Ecosystem)

> **وضعیت توسعه:** تکمیل و انطباق کامل **اسلایس اول** (Core Kernel Conformance)، **اسلایس دوم** (FastAPI Backend, Persian Localization, National Network Resilience)، **اسلایس سوم** (WebSocket Live Channel & Settlement ADR-003) و **بازطراحی کامل رابط کاربری مبتنی بر موبایل (Mobile-First / طرح تمو Temu-Style UX/UI) همراه با پیشتیبانی کامل PWA**.

---

## ۱. نمای کلی پروژه (Project Overview)
اکوسیستم معاملاتی و حراجی ملی **پرندو (Parando)** یک پلتفرم چندمستأجری (Multi-Tenant) دولتی و با حساسیت بالا برای مدیریت انواع بازارهای کالایی و سرمایه‌ای کشور است:
1. **طلا و مسکوکات گرانبها** (بسته‌های سکه تمام بهار آزادی استاندارد بانک مرکزی)
2. **پتروشیمی و فرآورده‌های پلیمری** (عرضه بورس انرژی و پلیمر صادراتی)
3. **خودرو و ناوگان تجاری سنگین** (کامیون‌های کشنده ترانزیتی تجاری صفر کیلومتر)
4. **املاک، اراضی و انبارهای مناطق آزاد** (مجتمع‌های لجستیکی با سند تک‌برگ)
5. **محصولات کشاورزی و اقلام صادراتی** (زعفران سوپر نگین پلمپ با گواهی کروسین)
6. **ماشین‌آلات و تجهیزات صنعتی سرمایه‌ای** (مراکز ماشین‌کاری دقیق ۵ محوره CNC)

---

## ۲. اسلایس سوم: ارتباط زنده وب‌سوکت و تسویه قطعی (Slice 3 Architecture)

### الف) کانال وب‌سوکت زنده (`/ws/competitions/{id}`)
- ایجاد کانال وب‌سوکت پرسرعت در **FastAPI** برای انتشار بلادرنگ تغییرات نردبان، جابجایی رتبه‌ها، شمارش معکوس و رویدادهای تسویه بدون نیاز به رفرش صفحه.
- پشتیبانی از پیام‌های هارت‌بیت (Ping/Pong) و همگام‌سازی خودکار در صورت نوسان ارتباط.
- بازتاب فوری وضعیت پیشنهادهای رقیب با انیمیشن‌های روان CSS.

### ب) موتور تسویه و کمیسیون (ADR-003 Settlement Integration)
- اندپوینت رسمی تسویه: `POST /api/v1/competitions/{competition_id}/settle`
- **محاسبات مالی قطعی:**
  - تعیین قیمت کشف‌شده نهایی (Clearing Price) بر اساس برترین رتبه نردبان.
  - کسر کارمزد پلتفرم حراج: **۵۰ صدم درصد (50 bps = 0.50%)**.
  - محاسبه مالیات بر ارزش افزوده قانونی: **۱۰٪ روی مبلغ کارمزد**.
  - محاسبه خالص پرداختی به حساب خزانه‌داری یا فروشنده دولتی (`net_seller_payout`).
  - **آزادسازی خودکار ودیعه‌های ۱۵٪:** انتشار رویداد `escrow.hold.released` برای تمام مشارکت‌کنندگان مغلوب رقابت.
  - **صدور حواله رمزنگاری‌شده (Settlement Voucher):** تولید هش یکتای SHA-256 غیرقابل جعل برای ممیزی قانونی دیوان محاسبات.

## ۳. بازطراحی کامل رابط کاربری موبایل و PWA (Temu-Style Mobile Experience)

### الف) ساختار پیمایش ۵ زبانه در پایین صفحه (`BottomNav.tsx`)
1. **خانه (Home):** ویترین محصولات در ساختار شبکه دو ستونه (Masonry Grid)، زمان‌سنج‌های شمارش معکوس و دکمه‌های ثبت پیشنهاد سریع.
2. **دسته‌ها (Categories):** کاوشگر بصری تالارهای کالایی با تعداد حراج‌های فعال.
3. **حراج زنده (Live):** ابزارک متحرک نردبان قیمت بلادرنگ متصل به وب‌سوکت با رصد رتبه‌های ۱ تا K و شبیه‌ساز رقابت.
4. **کیف و ودیعه (Wallet & Escrow):** مدیریت ضمانت‌نامه‌ها، سپرده مسدودی ۱۵٪ و اعتبارسنجی سقف تعهد (ADR-002 / K-INV-7).
5. **حاکمیت و اسناد (Profile & Governance):** داشبورد تسویه ADR-003، تاریخچه رویدادهای ممیزی (Audit Log)، آزمون‌های خودکار و گزارش‌های انطباق.

### ب) نوار جستجو و فیلترهای افقی (`TopHeader.tsx`)
- نوار چسبان (Sticky) با ورودی جستجوی هوشمند، آیکون‌های جستجوی صوتی (Mic) و تصویری (Camera).
- فیلترهای دسته‌بندی قرصی‌شکل با قابلیت اسکرول افقی روان.
- نشانگر برخط وضعیت شبکه ملی اطلاعات (NIN).
- کلید نصب برنامه پیشرو (PWA Install Button).

### ج) موتور تم دوگانه (Hybrid Theme Engine)
- **تم بازار عمومی (طرح تمو - Light Theme):** روشن، سرزنده، با کنتراست بالا برای خریداران و متقاضیان عمومی.
- **تم داشبورد امنیتی حاکمیتی (Dark Cyber Theme):** تاریک، امنیتی و ویژه ممیزی، ناظران دولتی و تطبیق ADRها.

### د) ابزارک نردبان قیمت متحرک و قانون TR-13 (`PriceLadderWidget.tsx`)
- نمایش جایگاه‌های ۱ تا K همراه با نشان‌های طلا، نقره و برنز.
- **انطباق TR-13:** نمایش صریح شماره ترتیب پیشنهاد (`Offer Sequence Number`) برای حل برابری قیمت؛ پیشنهادی که زودتر شماره دریافت کرده تقدم دارد.

### ه) مودال شناور پیشنهاد سریع (`QuickBidModal.tsx`)
- اعتبارسنجی خودکار سقف تعهد مالی متقاضی (K-INV-7) در برابر ودیعه مسدودی ۱۵٪.
- دکمه‌های گام سریع (+۱، +۲ و +۵ گام افزایش).
- پشتیبانی کامل از توکن یکتای تکرارناپذیری TR-12 (Idempotency Key).

### و) معماری پیشرو وب (PWA Architecture)
- شناسه و مانیفست کامل وب اپلیکیشن (`manifest.json`) با نام فارسی، رنگ‌های برند و حالت Standalone.
- سرویس‌ورکر هوشمند با افزونه `vite-plugin-pwa` برای ذخیره‌سازی محلی فونت‌ها و منابع اساسی.
- آیکون‌های استاندارد در ابعاد 192x192، 512x512، Maskable و Apple Touch Icon.
- بنر و راهنمای نصب درون‌برنامه‌ای با پشتیبانی اختصاصی از Safari iOS و مرورگرهای اندروید/دسکتاپ.

## ۵. راهنمای اجرا و آزمون‌ها (How to Run)

### ۱) اجرای فرانت‌اند مدرن (React + Vite PWA):
```bash
npm install
npm run dev
```
سامانه به نشانی `http://localhost:3000` در دسترس بوده و در تمام نمایشگرهای موبایل (iPhone, Android)، تبلت و دسکتاپ به صورت ریسپانسیو اجرا می‌شود.

### ۲) اجرای وب‌سرور و کانال زنده FastAPI:
```bash
pip install -r requirements.txt
uvicorn src.api.main:app --host 0.0.0.0 --port 8000 --reload
```
- مستندات OpenAPI / Swagger: `http://localhost:8000/docs`
- کانال وب‌سوکت زنده نردبان: `ws://localhost:8000/ws/competitions/{competition_id}`

### ۳) اجرای آزمون‌های خودکار:
```bash
python3 -m unittest discover tests -p "test_*.py"
```
تمامی آزمون‌های هسته دامنه، نردبان رتبه‌بندی، یکپارچگی قوانین و وب‌سرویس با موفقیت ۱۰۰٪ پاس می‌شوند.
