# سامانه حراج و مزایده ملی پاراندو (ParandO Auction Ecosystem)

> **وضعیت نهایی سامانه:** آماده تحویل نهایی (**Production-Ready**)  
> پوشش ۱۰۰٪ کلیه نیازمندی‌های **اسلایس اول** (Core Kernel Conformance)، **اسلایس دوم** (Persian RTL & National Network Resilience)، **اسلایس سوم** (WebSocket Live Updates & Settlement ADR-003) و **اسلایس چهارم** (ADR-004 Extension Architecture, Audit Trail & Deterministic Replay).

---

## ۱. نمای کلی پروژه (Project Overview)
اکوسیستم معاملاتی و حراجی ملی **پاراندو (ParandO)** یک پلتفرم چندمستأجری (Multi-Tenant) دولتی و سازمانی با حساسیت فوق‌العاده بالا برای مدیریت انواع بازارهای کالایی، انرژی و سرمایه‌ای کشور است. این سامانه با رعایت بالاترین استانداردهای معماری نرم‌افزار، اصول پایداری در شبکه ملی، محاسبات مالی دوطرفه بدون خطا و رعایت کامل الزامات سازمان بورس و اوراق بهادار، بانک مرکزی جمهوری اسلامی ایران و شبکه شاپرک توسعه یافته است.

### بازارهای ۶‌گانه پشتیبانی‌شده:
1. **طلا و مسکوکات گرانبها:** سکه تمام بهار آزادی استاندارد بانک مرکزی جمهوری اسلامی ایران (`TENANT-GOLD-CBI`)
2. **پتروشیمی و فرآورده‌های پلیمری:** گریدهای استاندارد عرضه بورس انرژی (`TENANT-ENERGY-PETRO`)
3. **خودرو و ناوگان تجاری سنگین:** کشنده‌های ترانزیتی تجاری و ناوگان حمل‌ونقل کشور (`TENANT-FLEET-LOGISTICS`)
4. **املاک، اراضی و انبارهای مناطق آزاد:** قطعات تجاری و صنعتی دبیرخانه شورای عالی مناطق آزاد (`TENANT-REALESTATE-FREEZONE`)
5. **محصولات کشاورزی و اقلام صادراتی:** زعفران سوپر نگین صادراتی بورس کالای ایران (`TENANT-AGRI-EXCHANGE`)
6. **ماشین‌آلات و تجهیزات صنعتی سرمایه‌ای:** مراکز ماشین‌کاری دقیق ۵ محوره CNC وزارت صمت (`TENANT-INDUSTRY-HEAVY`)

## ۲. دستاوردهای معماری در ۴ اسلایس توسعه

### اسلایس ۱: هسته محاسباتی ناب و قوانین نردبان (Core Kernel Conformance)
- **انطباق واژگان استاندارد TR-01 (بر پایه ADR-001):** تبدیل کامل مفاهیم عمومی به واژگان اختصاصی مزایده (`Competition`، `Offer`، `Offerer`، `LadderOffer`).
- **قانون تکرارپذیری قطعی TR-12:**
  - ارسال پیشنهاد با همان کلید `idempotencyKey` و مشخصات یکسان، نتیجه پیشین را بدون بازتولید یا انحراف وضعیت بازمی‌گرداند.
  - ارسال پیشنهاد با کلید تکراری ولی مشخصات متناقض بلافاصله خطای تعارض `OFFER_CONFLICT` صادر می‌کند.
- **شکست تساوی ترتیبی TR-13:** در صورت برابری مبالغ پیشنهادی، تقدم در رتبه‌بندی نردبان منحصراً بر اساس شماره توالی پیشنهاد (`sequence`) تعیین می‌شود و به هیچ وجه به ساعت سیستم وابسته نیست.
- **تضمین‌های مالی K-INV-7 و K-INV-14:** هسته محاسباتی ناب هرگز مستقیماً روی پایگاه داده نمی‌نویسد، بلکه از طریق درگاه خواندنی `CommitmentGuard` سقف اعتبار و وثیقه را استعلام می‌کند.

### اسلایس ۲: بومی‌سازی فارسی و پایداری در شبکه ملی (National Network Resilience)
- **رابط کاربری راست‌چین (RTL) و ارزی دوگانه:** نمایش همزمان ارزش‌ها به **ریال** و **تومان** با فونت وزیرمتن و ارقام فارسی.
- **صف آفلاین پایداری شبکه ملی (`OfflineResilienceManager`):**
  - در صورت بروز نوسان یا قطع اتصال در بستر اینترنت/شبکه ملی، پیشنهادها با کلید تکرارپذیری TR-12 در صف ایمن محلی ذخیره می‌شوند.
  - با اتصال مجدد، صف به صورت هوشمند و ترتیبی با هسته مرکزی همگام‌سازی (Flush) می‌گردد.

### اسلایس ۳: ارتباط زنده وب‌سوکت و ماژول تسویه ADR-003
- **هاب ارتباط زنده وب‌سوکت (`realtimeAuctionHub.ts`):**
  - پایش مداوم پینگ شبکه ملی (۱۸ تا ۳۲ میلی‌ثانیه).
  - انتشار بلادرنگ رویدادهای `LADDER_UPDATED`، `OFFER_PLACED`، `COUNTDOWN_TICK` و `STATUS_CHANGED`.
  - همگام‌سازی بین پنجره‌ها و تب‌های مرورگر با `BroadcastChannel`.
- **ماژول تسویه مالی و تسهیم وجوه (`settlement_module.ts`):**
  - پردازش رویداد رسمی `ladder.determined` همراه با تمبر امنیتی پلمپ نردبان (`sealDigest`).
  - محاسبه تفکیکی ارزش ناخالص، کارمزد پلتفرم (۰.۵٪)، مالیات ارزش افزوده (۱۰٪ VAT کارمزد)، عوارض نقل و انتقال قانونی (۰.۵٪) و خالص پرداختی به فروشنده.
  - صدور خودکار دستورات رفع مسدودی بانکی (`UNFREEZE_AUTHORIZED`) برای وثایق رقبای بازنده و نگه‌داشت وثیقه برنده جایگاه اول.
  - ثبت سند حسابداری دوبل دوطرفه دفتر کل (`Double-Entry Ledger`).

### اسلایس ۴: معماری افزونه‌ها و راستی‌آزمایی بازپخش قطعی (ADR-004 & Production Readiness)
- **چارچوب رجیستری هوک‌ها (`src/core/extension_hooks.ts`):**
  - الگوی میان‌افزار و رهگیر (Interceptor Pipeline) پیرامون هسته بدون دستکاری منطق ناب محاسباتی.
  - نقطه قلاب `beforeSubmitOffer`: اعتبارسنجی پیش‌ازورود با قابلیت جلوگیری فوری از پیشنهاد.
  - نقطه قلاب `afterOfferAccepted`: توزیع رویدادها، تلمتری نظارتی و غنی‌سازی لاگ‌ها.
  - نقطه قلاب `onOfferRejected`: ثبت رخدادهای خطای اعتبارسنجی و پایش امنیتی.
  - نقطه قلاب `onLadderDetermined`: اتصال به چرخه بایگانی نظارتی و تسویه مالی.
- **هوک‌های استاندارد امنیتی و نظارتی:**
  1. **`SecurityVelocityHook`:** جلوگیری از حملات DoS و ارسال متوالی غیرمجاز توسط ربات‌ها (کنترل نرخ زمانی).
  2. **`AMLComplianceHook`:** کنترل سقف تراکنش‌های مبارزه با پولشویی و جهش‌های غیرمتعارف قیمت نسبت به قیمت پایه (Fat-Finger Protection).
  3. **`MarketIntegrityHook`:** صیانت از سلامت بازار و جلوگیری از رفتارهای مشکوک اسپوفینگ و رقابت بی‌مورد با خود.
- **سامانه ممیزی نظارتی و بازپخش تراکنش‌ها (`src/components/AuditComplianceModal.tsx`):**
  - صدور سند رسمی ممیزی بورس و اوراق بهادار همراه با تمبر رمزنگاری‌شده (`Cryptographic Seal`).
  - **موتور بازپخش قطعی (Deterministic Replay Verification Engine):** اجرای مجدد جریان رویدادهای تاریخی از زمان مبدأ (T=0) در یک ساندباکس ایزوله و اثبات انحراف صفر درصدی رتبه‌ها و نردبان (**Zero-Drift Certified**).
  - کنسول مدیریت برخط فعال/غیرفعال‌سازی هوک‌ها و جدول لاگ‌های تلمتری امنیتی.

## ۵. راهنمای راه‌اندازی و استقرار نهایی (Production Handover Guide)

### پیش‌نیازها:
- Node.js نسخه 18 یا بالاتر
- npm یا bun

### گام ۱: نصب وابستگی‌ها
```bash
npm install
```

### گام ۲: اعتبارسنجی تایپ‌ها و کیفیت کد (Lint / Typecheck)
```bash
npm run lint
```
*خروجی تضمین‌شده: ۰ خطا و انطباق کامل تایپ‌اسکریپت.*

### گام ۳: بیلد تولیدی (Production Build)
```bash
npm run build
```

### گام ۴: اجرای سرور کامل (Full-Stack Dev / Prod Server)
```bash
npm run dev
```
سرویس وب و وب‌سوکت روی آدرس `http://localhost:3000` (مسیر وب‌سوکت: `ws://localhost:3000/ws`) در دسترس قرار می‌گیرد.

## ۶. شیوه اجرای آزمون‌های خودکار و راستی‌آزمایی زنده
1. **ترمینال آزمون‌های داخلی:** در نوار بالای سامانه روی دکمه سبز رنگ **«آزمون‌های هسته و API»** کلیک کنید. تمام ۲۳ آزمون جامع در دسته‌های نردبان، هسته، یکپارچگی، تسویه و افزونه‌های ADR-004 به صورت خودکار اجرا شده و نشان سبز دریافت می‌کنند.
2. **راستی‌آزمایی بازپخش قطعی (Zero-Drift Certified):** در نوار بالا روی دکمه بنفش **«ممیزی و بازپخش»** کلیک کرده و به برگه **«موتور بازپخش قطعی»** بروید. با فشردن دکمه «اجرای بازپخش قطعی تراکنش‌ها»، کل جریان معاملات در یک ساندباکس مجزا شبیه‌سازی شده و برابری ۱۰۰٪ با نرخ انحراف ۰.۰۰٪ به صورت زنده تایید می‌گردد.
